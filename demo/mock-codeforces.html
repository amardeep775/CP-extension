C2. Powering the Hero (hard version)
time limit per test: 2.0 seconds
memory limit per test: 512 megabytes

This is a hard version of the problem. It differs from the easy version only by the constraints on $n$ and $\sum n$.

There is a deck of $n$ cards. Each card is either a hero card with power $s_i = 0$ or a bonus card with power $s_i > 0$.

You can take cards from the top of the deck one by one. You want to maximize the total army power by assigning bonus cards to your heroes!

Input

The first line contains an integer $t$ ($1 \le t \le 10^4$) — the number of test cases.

The second line contains $n$ ($1 \le n \le 2 \cdot 10^5$) — the number of cards.

Sample Input:
5
5
3 3 0 0 0

Sample Output:
6
